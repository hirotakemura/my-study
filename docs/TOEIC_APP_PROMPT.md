# TOEIC学習管理PWAアプリの作成

## 概要
TOEIC L&Rの学習を管理する、スマホで使うPWAアプリを作成してください。
利用者は社会人で、平日は仕事（残業1〜2時間）、**通勤2時間を英語学習にあてる**。週末はOutSystems資格の学習・受験があるため、英語は平日の通勤が中心。

前提：3年前のスコア490（L295／R195）。本番は2026年12月19日（土）、目標650点。800点は2027年夏の目標。
リーディングが大きな弱点のため、単語と文法の土台づくりを優先する。

## 技術要件
- Vite + React + TypeScript、vite-plugin-pwaでPWA化（ホーム画面に追加でき、オフラインで動作）
- データはlocalStorageに保存し、JSONでのエクスポート/インポート（バックアップ）機能をつける
- 計画データ（ロードマップ）はアプリ本体から分離したJSONファイル（public/data/配下）で管理し、後から修正しやすくする
- スマホ縦画面を最優先にしたレスポンシブデザイン、ダークモード対応（端末に合わせる／ライト／ダーク）
- 画面遷移はハッシュルーティング（GitHub Pagesでリロードしても404にならない）
- GitHub Pages（GitHub Actionsで自動デプロイ）とVercelへのデプロイ手順をREADMEに記載

## 画面構成（下部タブ）
ホーム／記録／ロードマップ／スコア／振り返り（設定は右上の⚙️）

## 機能1：ホーム（今日やること）
- 今日の日付から、ロードマップの「今の期間」を自動判定し、期間名・残り日数・今週やること（チェックリスト）を表示
- **通勤メニュー**：今の期間の通勤中メニュー（内容と目安の分数）を表示。各項目を「行き」「帰り」のどちらでやったかワンタップでチェックでき、チェックした項目の分数がその日の学習時間に自動で加算される（取り消しも可能）
- 本番（12/19）までのカウントダウンと目標点
- 今日の学習時間の記録（分単位、+10/+15/+30ボタンと任意入力、内訳：単語／文法／リスニング／Part5-6／Part7／模試復習 から選べる）
- 連続学習日数（ストリーク）と今週の合計学習時間、週の目標時間（既定10時間＝通勤2時間×5日、設定で変更可）に対する達成率
- 疲れた日用の「最低ライン」（単語15分）の達成チェック。達成した日はストリークが続く
- 期間の最終週や本番1週間前（12/12以降）には「新しい教材に手を出さず復習のみ」などの注意を目立つ形で表示

## 機能2：ロードマップ
以下を期間ごとのチェックリストとして表示し、今日がどの期間かを自動判定して強調する（今の期間は最初から開いた状態）。

**9/28〜10/4：準備**
- 公式問題集で1回分を解いて現在地を確認
- 12月試験の申込期間を公式サイトで確認し、カレンダーに登録

**10/5〜10/31：土台づくり（通勤2時間）**
- 単語45分（TOEIC頻出単語帳を1冊に絞って周回）
- 文法45分（中学〜高校基礎文法の復習）
- リスニング30分（公式問題集の音声を聞き流し＋シャドーイング）

**11/1〜11/30：Part別対策（通勤2時間）**
- Part 5/6の問題演習を毎日30問
- Part 7の長文を毎日1〜2題（時間を計る）
- Part 3/4のシャドーイング
- 単語帳の周回は継続

**12/1〜12/18：実戦（週末＋通勤）**
- OutSystemsの受験が落ち着いた週末に、公式問題集で2時間通しの模試
- 平日の通勤は模試で間違えた問題の復習
- 本番1週間前からは新しい教材に手を出さず、復習のみ

**12/19：本番**

- 各期間に「目安の学習時間」と「実績の学習時間」を並べて表示する
- 単語帳の周回数（1周目・2周目…）を記録できるカウンターをつける

## 機能3：スコア記録
- 模試・公式問題集のスコアをL/R別に記録（日付、L、R、メモ。L・Rは5〜495の5点刻みで入力チェック）
- 合計・L・Rの推移を折れ線グラフで表示（目標650点の破線、最新値のラベル、タップで値を表示するツールチップ、グラフの下に表形式の一覧）
- 3年前のスコア（490）を基準点として表示し、最新スコアとの差を表示
- 目標までの残り点数と、L・Rのどちらを伸ばすべきかの簡単なコメント（例：Rが目標配分より低い場合は「リーディング強化」）

## 機能4：振り返り
- 毎週日曜はアプリを開いたときに「今週の振り返り」画面を自動表示（1日1回）
- 週ごとに：学習時間の合計（前週比）、日ごとの学習時間の棒グラフ（内訳別に色分け）、最低ラインだけの日数、今週記録したスコア
- 来週の予定（来週にかかる期間の通勤メニュー、本番が来週なら強調）
- 振り返りメモを週ごとに保存でき、過去のメモも見返せる

## 機能5：設定・バックアップ
- JSONのエクスポート／インポート
- **旧アプリからの移行**：旧アプリ（OutSystems学習管理アプリ）の設定画面で書き出した「TOEICデータ」のJSONを読み込めるようにする。形式は次のとおり：

```json
{
  "app": "my-study-toeic-export",
  "version": 1,
  "exportedAt": "2026-09-30T00:00:00.000Z",
  "studyLogs": [{ "id": "文字列", "date": "YYYY-MM-DD", "minutes": 30, "createdAt": "ISO日時" }],
  "minimumDone": { "YYYY-MM-DD": true },
  "toeicChecks": { "prep-1": true },
  "toeicScores": [{ "id": "文字列", "date": "YYYY-MM-DD", "listening": 300, "reading": 250, "note": "任意" }],
  "reviewMemos": { "YYYY-MM-DD（週の月曜日）": "メモ本文" }
}
```
  - studyLogs は内訳なしの英語学習時間として取り込む
  - toeicChecks のキーは下記ロードマップJSONのタスクidと同じ
  - reviewMemos は旧アプリでOutSystemsと共用だったため、取り込み時に「旧アプリのメモ」と分かる表示にする
- 週の目標時間、ダークモードの設定
